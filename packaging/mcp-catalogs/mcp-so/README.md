## Overview

[mcp.so](https://mcp.so/) is a third-party MCP marketplace / directory. Submissions are
community-driven (GitHub issue or site **Submit** flow). This folder holds copy-ready listing
text so maintainers can open a submission without re-deriving metadata.

## Operator steps

1. Open [`listing.md`](./listing.md) and confirm version / release asset URLs.
2. Submit via https://mcp.so/ (navigation **Submit**) or their linked GitHub issues form.
3. Paste the issue body template from `listing.md`.
4. When the public listing URL exists, update
   [`docs/registry-distribution-matrix.md`](../../../docs/registry-distribution-matrix.md)
   and mark **live**.
