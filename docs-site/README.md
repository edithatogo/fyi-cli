# FYI CLI Documentation Site

This is the bleeding-edge documentation site for FYI CLI, built using **Astro** and **Starlight**.

## Setup & Running

To run the documentation site locally:

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Start development server**:
    ```bash
    npm run dev
    ```
    This launches a hot-reloaded development server at `http://localhost:4321`.

3.  **Build production version**:
    ```bash
    npm run build
    ```

4.  **Preview production build**:
    ```bash
    npm run preview
    ```
